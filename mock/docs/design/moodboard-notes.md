# Moodboard Notes

添付画像は、LINE アカウント CRM の管理画面を PC で扱いながら、右側で LIFF スマホ体験も確認できる SaaS ダッシュボードです。

- 基調は淡いブルーと白。安心感・管理しやすさ・LINE 連携の清潔感を優先します。
- CTA は LINE グリーンとプロダクトブルーの 2 軸に限定し、カード内の小さな状態色だけを補助的に使います。
- レイアウトは左固定ナビ、上部検索、横長ヒーロー、KPI カード列のあと、**上段**が「クイックアクション（左・広い）＋最近のアクティビティ＋ LIFF プレビュー」、**下段**が「運用の安心＋友だち数の推移」の3カラム（右端はプレビュー列に揃えるスペーサー）が正本です。
- 装飾・チャート装飾は `apps/web/assets/design-elements/`（元 `/Users/apple/Downloads/design_elements`）の PNG をレイヤー合成で使います。参照モック画像は `apps/web/assets/dashboard-mock-reference.png` です。
- 管理者は PC 前提で情報密度を保ち、エンドユーザー体験はスマホモックで確認できる形にします。
- 角丸・薄いボーダー・ごく軽い影で、重いエンタープライズ感ではなく明るい運用管理画面に寄せます。
